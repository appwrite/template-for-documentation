# AdLibrary

![AdLibrary Illustration](https://images.unsplash.com/photo-1633356122544-f134324a6cee?ixlib=rb-4.0.3&auto=format&fit=crop&w=1000&q=80)

A comprehensive Android advertising library designed to simplify ad management, caching, and configuration using Appwrite as a remote backend.

Supports various ad formats including Native, Interstitial, Rewarded, and App Open ads, with built-in caching and offline support capabilities.

## Features

- 📱 **Multi-Format Support** - Native, Interstitial, Rewarded, Rewarded Interstitial, App Open, and Banners.
- 🚀 **Smart Caching** - Built-in caching mechanism to load ads instantly, with configurable retention policies.
- ⚙️ **Remote Configuration** - Integrated with Appwrite for dynamic ad unit mapping and configuration.
- ✈️ **Offline Support** - Serve cached ads when the device is offline.
- 🛠️ **DI Ready** - First-class support for Koin dependency injection.

## Project Vision

AdLibrary aims to provide a seamless experience for developers to integrate multiple ad providers (like AdMob) with a centralized remote configuration, ensuring maximum flexibility and revenue optimization without constant app updates.
